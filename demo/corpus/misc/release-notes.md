# ZENITH v1.0 release notes

- Added metadata filtering with eq/in/range/exists/and/or/not operators.
- Added a pure-Go HNSW ANN index persisted as a sidecar file.
- Added cross-encoder reranking for the hybrid search top results.
- Added OCR text extraction for scanned images, opt-in via Tesseract.
- Typo tolerance scales edit distance with word length for better precision.
