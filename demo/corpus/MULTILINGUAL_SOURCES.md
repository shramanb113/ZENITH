## Source attribution

`taj_mahal.txt`, `cricket.txt`, `himalaya.txt` are lead-section extracts fetched live from Hindi
Wikipedia (`hi.wikipedia.org`) via the public MediaWiki API on 2026-10-03, used here for local
cross-lingual retrieval testing (`labse`). Content is CC BY-SA 4.0:

- ताज महल — https://hi.wikipedia.org/wiki/ताज_महल
- क्रिकेट — https://hi.wikipedia.org/wiki/क्रिकेट
- हिमालय — https://hi.wikipedia.org/wiki/हिमालय

`hindi.txt`, `french.txt`, `german.txt`, `spanish.txt`, `japanese.txt` are hand-written one- or
two-sentence fixtures, not sourced externally.
